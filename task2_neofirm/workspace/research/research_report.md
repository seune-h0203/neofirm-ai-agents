## Q1: 핵심 고객 Pain — 입시 컨설팅 시장

**NLM Conversation ID:** 2013cf58-2c37-4677-a76a-105200185ff5
**Source:** NeoFirm_입시컨설팅_1.pptx [1]

**학생·학부모 핵심 Pain:**
- **진학 불확실성 및 불가역성:** "내 성적으로 어디에 지원해야 하지?" — 입시 결과는 대학 진학이라는 되돌릴 수 없는 결과로 이어짐
- **잘못된 전략의 고비용:** 지원 실패는 시간과 기회 모두에서 매우 큰 손실
- **정보의 파편화:** 전형·대학 정보가 흩어져 있고, 전문가 상담은 비싸고 접근이 어려움

**기존 전문가 상담의 구조적 문제:**
- 전문가 1인이 데이터 수집→학생부 분석→대학/전형 비교→지원전략 수립→상담까지 모든 단계를 혼자 처리
- 반복 가능한 분석 업무까지 인력 의존 → 긴 처리 시간 + 높은 상담 비용
- 표준화된 프로세스 없이 컨설턴트 개인 역량에 의존 → 컨설턴트별 품질 편차

## Q2: AI vs 전문가 역할 분리

**NLM Conversation ID:** 706f3827-6686-457c-a72f-8272f0d662fe
**Source:** NeoFirm_입시컨설팅_1.pptx [1, 2]

**AI 담당 — Scale (반복·표준화 가능 업무):**
- 학생 성적·학생부 데이터 수집·분석
- 대학·전형 정보 비교 자동화
- 지원 가능성 분석 및 수시 6장 후보군 자동 생성
- 시즌 내 성적·전형 변화 모니터링
- 전략 시뮬레이션 수행

**전문가 담당 — Judgment (표준화 불가 판단 영역):**
- 학생 개인 목표·상황·맥락 파악
- AI 분석 결과 검토 및 수정
- 우선순위 판단 및 최종 수시 6장 전략 결정
- 학생·학부모 1:1 상담
- 예외 상황 처리 (특기자 전형, 가정환경, 심리적 요인 등)

## Q3: 고객 반복 이용 메커니즘

**NLM Conversation ID:** 66401175-ee3f-4400-b5e1-f9e74651013a
**Source:** NeoFirm_입시컨설팅_1.pptx [1, 2]

**반복 이용 발생 이유:**
- 성적·학생부·지원전략이 시즌 내내 지속적으로 변화
- AI 모니터링 → 전문가 재검토 → 전략 업데이트의 루프가 반복
- "전략 생성 → 실행 → 변화 감지 → 재분석" 사이클이 최종 지원까지 계속됨

**NeoFirm B2B 특성과의 정합성:**
- 표준화 어려운 업무: 학생마다 다른 상황 → AI 분석 + 전문가 판단
- 고객 반복 이동: 성적·학생부·지원전략이 시즌 내내 계속 변화
- 데이터 학습 효과: 학생 데이터 + 전문가 판단 + 실제 지원 결과가 축적

## Q4: GTM 전략 — 무료 AI 진단 → 유료 전환

**NLM Conversation ID:** 9b64da24-65c5-4b86-9f35-2f6961e9fd2e
**Source:** NeoFirm_입시컨설팅_1.pptx [1]

**5단계 GTM 구조:**
1. **무료 AI 진단 (Acquisition Hook):** "내 성적으로 어디까지 갈 수 있을까?" — 고3 학생·학부모 대규모 유입
2. **개인별 진단 결과 제공:** 성적·학생부 기반 맞춤 분석 결과 즉각 전달 → 서비스 가치 체감
3. **지원전략 관심 유도:** 수시 6장 구체 전략에 대한 고객 니즈 확인 및 관심도 제고
4. **유료 컨설팅 전환:** AI + 전문가 하이브리드 컨설팅 시작 (수시 6장 전략 상담)
5. **시즌 내 반복 사용:** 성적·학생부·전략 변화 따라 시즌 내내 재사용 → 데이터 축적

**핵심 전환 논리:** 무료 진단으로 "내 상황에 맞는 구체적 전략이 필요하다"는 인식 형성 → 자연스러운 유료 전환

## Q5: 데이터 플라이휠 / Moat

**NLM Conversation ID:** 928d6014-be3f-4a44-a913-3c8ad97e7121
**Source:** NeoFirm_입시컨설팅_1.pptx [1, 2]

**플라이휠 3대 축:**
- 학생 데이터 (AI Scale): 수집·분석·비교, 지원 가능성 분석, 수시 6장 후보군
- 전문가 판단 (Trust): 목표 파악, AI 결과 검토, 최종 전략 결정, 상담
- 실제 지원 결과: 합격/불합격 데이터 축적 → 다음 추천 정교화

**Moat 작동 순환:**
고객 유입 → 무료 진단 → 유료 전환 → 하이브리드 전략 수립 → 실제 지원 → 합불 결과 축적 → 추천 정교화 → 서비스 가치 상승 → 더 많은 학생 유입

**경쟁 우위:** 학생이 늘어날수록 지원 데이터가 축적되고, 데이터가 추천을 정교하게 만들며, 이것이 다시 서비스 가치를 높이는 선순환 구조

## Q6: AS-IS vs TO-BE 비교

**NLM Conversation ID:** 0b225779-c974-445e-bbd5-750516fa5494
**Source:** NeoFirm_입시컨설팅_1.pptx [1, 2]

| 구분 | AS-IS (기존) | TO-BE (NeoFirm) |
|------|-------------|-----------------|
| 처리 주체 | 전문가 1인이 전 과정 처리 | AI(반복) + 전문가(판단) 역할 분리 |
| 처리 시간 | 길고 비효율적 | AI 자동화로 단축 |
| 비용 | 높은 상담 비용 | 합리적 구조 (AI Scale) |
| 품질 | 컨설턴트별 편차 | 표준화된 AI 분석 + 전문가 최종 검토 |
| 고객 관계 | 단발성 상담 | 시즌 내 반복 사용 구조 |
